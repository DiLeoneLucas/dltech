Mercurio

Sistema de Gerenciamento de Estoque

Projeto: Mercurio
Linguagem: PHP
Banco de dados: MySQL
Plataforma: Web

1. Sobre o projeto

O Mercurio é um sistema web desenvolvido para gerenciamento e controle de estoque, oferecendo recursos para administração de produtos, fornecedores, usuários e movimentações de materiais.

A aplicação foi desenvolvida em PHP e organizada em módulos, permitindo centralizar operações administrativas e facilitar o acompanhamento das movimentações realizadas no estoque.

O projeto busca proporcionar maior organização, rastreabilidade e controle dos processos relacionados à gestão de materiais.

2. Objetivos

  • Centralizar o gerenciamento de materiais e produtos.
  • Controlar entradas e baixas de estoque.
  • Administrar fornecedores.
  • Gerenciar usuários e permissões de acesso.
  • Manter histórico das movimentações.
  • Disponibilizar relatórios para acompanhamento administrativo.
  • Facilitar a rotina operacional e o controle de materiais.

3. Funcionalidades

3.1. Gestão de estoque

  • Cadastro de produtos e materiais.
  • Atualização de informações do estoque.
  • Registro de movimentações.
  • Controle de baixas de materiais.
  • Consulta de informações dos produtos.

3.2. Gestão de fornecedores

  • Cadastro de fornecedores.
  • Atualização de informações cadastrais.
  • Consulta e listagem de fornecedores.

3.3. Gestão de usuários

  • Cadastro de usuários.
  • Atualização de informações.
  • Listagem e gerenciamento de contas.
  • Autenticação de acesso.
  • Redefinição de senha.

3.4. Relatórios e histórico

  • Consulta do histórico de movimentações.
  • Geração de relatórios.
  • Acompanhamento das operações de estoque.

3.5. Administração e segurança

  • Tela de autenticação.
  • Separação de áreas administrativas.
  • Gerenciamento de sessões.
  • Controle de acesso às funcionalidades.

4. Tecnologias utilizadas

O Mercurio utiliza tecnologias voltadas ao desenvolvimento web, integração com banco de dados e organização de dependências da aplicação.

Tecnologia Aplicação

6. Ambiente de desenvolvimento

Para executar o projeto localmente, recomenda-se utilizar:

  • Windows ou Linux.
  • Servidor web Apache.
  • PHP.
  • MySQL ou MariaDB.
  • XAMPP ou ambiente equivalente.
  • Composer.

7. Instalação e configuração

7.1. Clonar o repositório

Clone o repositório do projeto utilizando o Git: 

git clone https://github.com/DiLeoneLucas/Mercurio.git

7.2. Acessar o diretório

Entre na pasta do projeto: 

cd Mercurio

7.3. Configurar o servidor web

Disponibilize o projeto no diretório público do servidor web.

No XAMPP, por exemplo: 

C:\xampp\htdocs\Mercurio

7.4. Iniciar os serviços

Inicie os serviços Apache e MySQL pelo painel de controle do XAMPP ou pela ferramenta correspondente ao ambiente utilizado.

7.5. Configurar o banco de dados

Configure a conexão com o banco de dados conforme os parâmetros utilizados nos arquivos de configuração do projeto.

7.6. Importar a estrutura do banco

Importe a estrutura do banco de dados, caso possua o respectivo arquivo SQL.

7.7. Acessar a aplicação

Após a configuração do ambiente, acesse a aplicação pelo navegador: 

http://localhost/Mercurio/

Importante: os parâmetros de conexão e a estrutura do banco devem ser conferidos no ambiente de implantação. O repositório não apresenta um script SQL de instalação identificado na estrutura principal.

8. Segurança e boas práticas

Por trabalhar com informações administrativas e dados de estoque, recomenda-se adotar medidas para proteger a aplicação e os dados armazenados.

  • Restringir o acesso às áreas administrativas.
  • Utilizar senhas seguras.
  • Proteger as credenciais de conexão com o banco de dados.
  • Validar os dados recebidos pelos formulários.
  • Utilizar consultas preparadas para operações SQL.
  • Implementar controle adequado de sessões.
  • Manter backups periódicos do banco de dados.
