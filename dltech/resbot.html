ReBot

Automação de Redefinição de Senhas no Microsoft Intune

Versão: 1.0
Plataforma: Windows
Linguagem: Python
Desenvolvimento: Lucas Fernandes Di Leone

1. Sobre o projeto

O ReBot é uma ferramenta de automação desenvolvida em Python para agilizar o processo de redefinição de senhas de usuários em lote no ambiente Microsoft Intune.

A solução utiliza a biblioteca Pandas para realizar a leitura e o processamento de listas de usuários disponibilizadas em arquivos CSV, enquanto o Selenium automatiza as interações com o navegador para executar as operações no ambiente administrativo.

A aplicação foi desenvolvida para reduzir atividades operacionais repetitivas, otimizar o atendimento técnico e aumentar a produtividade da equipe de TI, oferecendo maior agilidade e padronização aos procedimentos de gerenciamento de contas.

2. Objetivos

  • Automatizar a redefinição de senhas em lote.
  • Processar listas de usuários através de arquivos CSV.
  • Reduzir intervenções manuais nas atividades de suporte.
  • Diminuir o tempo necessário para execução de tarefas repetitivas.
  • Aumentar a produtividade da equipe de TI.
  • Padronizar processos operacionais de atendimento.

3. Funcionamento

O fluxo de funcionamento da ferramenta é dividido em etapas:

3.1 Inicialização

Abertura do Google Chrome com depuração remota habilitada para permitir a comunicação com o Selenium.

3.2 Leitura dos dados

Utilização do Pandas para carregar e processar a relação de usuários disponibilizada em arquivo CSV.

3.3 Automação

Utilização do Selenium para interagir com o navegador e executar as operações no Microsoft Intune.

3.4 Processamento em lote

Execução sequencial das redefinições de senha dos usuários selecionados.

7. Pré-requisitos

Para executar o projeto, é necessário:

  • Windows.
  • Python instalado.
  • Google Chrome instalado.
  • Bibliotecas Pandas e Selenium.
  • Acesso autorizado ao ambiente Microsoft Intune.
  • Permissões necessárias para realizar a redefinição de senhas.

8. Inicialização

O repositório disponibiliza o arquivo Abre chrome.bat, utilizado para iniciar o Google Chrome com a porta de depuração remota 9222.

8.1 Comando de inicialização

@echo off
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222

8.2 Etapas para execução

  1. Abra o diretório do projeto.
  2. Execute o arquivo Abre chrome.bat.
  3. Aguarde a inicialização do navegador.
  4. Execute os scripts Python conforme a configuração do ambiente.

9. Segurança

Como a ferramenta realiza operações administrativas relacionadas a contas de usuários, alguns cuidados são fundamentais:

  • Utilizar exclusivamente em ambientes autorizados.
  • Proteger os arquivos CSV utilizados no processamento.
  • Não armazenar senhas ou credenciais diretamente no código.
  • Não compartilhar informações pessoais dos usuários.
  • Restringir o acesso aos arquivos e ao ambiente de execução.
  • Garantir que as operações sejam realizadas por profissionais autorizados.

Recomendação: a automação deve ser executada somente por profissionais com autorização administrativa, respeitando as políticas internas de segurança e proteção de dados da organização.
