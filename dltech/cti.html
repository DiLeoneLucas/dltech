UTI-CTI

Sistema de Gerenciamento de Chamados de TI

📌 Sobre o projeto

O UTI-CTI é um sistema web desenvolvido para gerenciamento de incidentes e requisições de suporte técnico em ambiente educacional.

A aplicação foi criada para facilitar a comunicação entre professores e a equipe de Tecnologia da Informação, permitindo registrar problemas técnicos, acompanhar chamados e organizar o atendimento das solicitações.

O sistema foi desenvolvido utilizando PHP e MySQL, com interface baseada em Bootstrap, proporcionando uma solução centralizada para o gerenciamento das atividades de suporte técnico.

🎯 Objetivos

  • Centralizar a abertura de chamados de suporte técnico.
  • Facilitar a comunicação entre professores e equipe de TI.
  • Organizar incidentes e requisições por sala.
  • Permitir o acompanhamento dos atendimentos.
  • Disponibilizar um painel visual para monitoramento dos chamados.
  • Manter histórico das solicitações e atualizações.
  • Melhorar a organização e o controle operacional do suporte técnico.

⚙️ Funcionalidades

📝 Abertura de chamados

  • Registro de novos incidentes e requisições.
  • Identificação do professor solicitante.
  • Identificação do número da sala.
  • Classificação do tipo de chamado.
  • Descrição detalhada do problema.

Categorias disponíveis:

  • PC.
  • Projetor.
  • Rede.
  • Outros.

👨‍💻 Área do técnico

  • Autenticação de técnicos.
  • Visualização dos chamados em aberto.
  • Acompanhamento dos incidentes.
  • Atualização dos chamados.
  • Criação e gerenciamento de usuários.
  • Acesso ao histórico de atendimentos.

📊 Painel de monitoramento

O sistema possui um painel visual para acompanhamento da quantidade de chamados abertos.

Características:

  • Exibição da quantidade de chamados pendentes.
  • Atualização automática a cada 90 segundos.
  • Indicação visual de chamados em aberto.
  • Alteração da cor de fundo conforme a existência de chamados pendentes.

🔎 Histórico de incidentes e requisições

Permite consultar atendimentos anteriores utilizando filtros como:

  • Número da sala.
  • Tipo de chamado.
  • Status do atendimento.
  • Técnico responsável.
  • Professor solicitante.

🔔 Notificações

Após a abertura de um chamado, o sistema apresenta uma confirmação ao solicitante, informando que a equipe de suporte técnico foi notificada.

🏫 Acompanhamento por sala

O sistema utiliza o endereço IP do solicitante para identificar chamados associados à estação de acesso, permitindo que o professor acompanhe as solicitações relacionadas à sua sala.

🚀 Ambiente de desenvolvimento

Para executar o projeto localmente, recomenda-se:

  • Windows ou Linux.
  • Apache.
  • PHP.
  • MySQL ou MariaDB.
  • XAMPP ou ambiente equivalente.
  • Navegador web atualizado.

📥 Instalação

1. Clonar o repositório

git clone https://github.com/DiLeoneLucas/UTI-CTI.git

2. Acessar o diretório

cd UTI-CTI

3. Configurar o servidor

Disponibilize os arquivos do projeto no diretório público do Apache.

Exemplo utilizando XAMPP:

C:\xampp\htdocs\UTI-CTI

4. Configurar o banco de dados

O arquivo control/db_classes.php contém a classe responsável pela conexão com o MySQL.

Configuração utilizada no código disponibilizado: 

private $host = 'localhost';
private $user = 'root';
private $psw = '';
private $database = 'dbcti_homolog';

Ajuste os parâmetros conforme o ambiente de instalação.

5. Preparar o banco de dados

É necessário disponibilizar a estrutura do banco de dados utilizada pela aplicação, incluindo as tabelas e views consultadas pelo sistema.

6. Acessar a aplicação

http://localhost/UTI-CTI/

🔐 Segurança e controle de acesso

O sistema possui autenticação para acesso à área administrativa dos técnicos.

Recomendações para implantação:

  • Restringir o acesso às funcionalidades administrativas.
  • Utilizar senhas seguras e armazenamento com hash.
  • Validar os dados recebidos pelos formulários.
  • Utilizar consultas preparadas para operações SQL.
  • Proteger as sessões dos usuários.
  • Restringir o acesso ao banco de dados.
  • Evitar exposição de informações internas da infraestrutura.
